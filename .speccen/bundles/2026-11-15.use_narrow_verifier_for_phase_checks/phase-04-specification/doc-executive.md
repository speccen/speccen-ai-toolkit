# use narrow verifier for phase checks — Business Outcome Brief (intent, seed)

## Capability To Be Delivered
- Each autonomous phase ends with a gate check. In the gate check, a checker run reads only a short list of facts about the code.
- One checker run takes about 5 minutes or less. Today one checker run can take 13 minutes.

## Risk Delta (expected)
- Risk this is expected to close: long and costly checker runs that repeat the research of the phase.
- Risk this is expected to close: slips that stop or slow an autonomous run. A slip is a small error in a line number, a path or a count.
- Risk being accepted: the checker run does not read the phase records. The delegate's own review covers the phase records.

## What It Will Unblock
- Autonomous runs that finish faster, so teams can use autonomous mode more often.

## Scope Note
- TCO / cost / budget: out of scope for this feature-level brief.
