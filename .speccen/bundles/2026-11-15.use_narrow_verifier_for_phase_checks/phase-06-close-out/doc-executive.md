# use narrow verifier for phase checks — Business Outcome Brief (seed)

Intent: [Phase 04 executive seed](../phase-04-specification/doc-executive.md). Outcome: the rules are delivered as intended. The time gain is not measured yet.

## Capability Delivered
- Each autonomous phase ends with a gate check. In the gate check, a checker run now reads only a short list of facts about the code.
- The change ships in version `26.1116.1`. It applies from the next bundle.

## Risk Delta
- Risk closed: long checker runs that repeat the research of the phase. In this bundle, one phase used 9 checker runs, mostly on wording.
- Risk closed: slips that stop or slow an autonomous run.
- Risk accepted: the checker run does not read the phase records. The delegate's own review covers the phase records.
- Risk open: the time gain is expected, not measured. Measure it on the next autonomous bundle.

## What It Unblocks
- Autonomous runs that finish faster, so teams can use autonomous mode more often.
