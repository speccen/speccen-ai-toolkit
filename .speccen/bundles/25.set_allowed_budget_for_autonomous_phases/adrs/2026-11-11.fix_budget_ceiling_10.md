# ADR 2026-11-11 — Fix budget ceiling: 3 or 10 fix attempts

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | Fix budget ceiling: 3 or 10 fix attempts |
| **Status** | DECIDED |
| **Context** | Issue #25 adds a `fixes` key: how many fix attempts the delegate makes on a failing gate test before it stops. The brief caps it at 3 (§2 guard 3) and rejects "Unbounded retries" (§4). The delegate answered 03/3 with "keep 3" under `stops: proceed` and recorded it as DD-12, `MATERIAL — unconfirmed`, because the Architect had also said "I don't know how to express in simple English that have to loop until issues are fixed" (log 15:45). The end-of-run review put it to the Architect as R/1. |
| **Decision** | "Keep the maximum of 3 fix attempts, rather than looping until the check passes?" → "1 max loop 10" — the Architect, review R/1 (log 21:58). `fixes` takes `1` – `10`, default `5` ([ADR 2026-11-12](./2026-11-12.fix_budget_default_5.md)); a value that is not a whole number from `1` to `10` counts as `1`. DD-12 is OVERRIDDEN. |
