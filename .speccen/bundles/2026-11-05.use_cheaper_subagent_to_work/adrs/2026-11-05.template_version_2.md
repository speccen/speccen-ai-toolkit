# ADR 2026-11-05 — Config template version 2 for the new `model` keys

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | Config template version 2 for the new `model` keys |
| **Status** | DECIDED |
| **Context** | A4 adds `model` to `specification` and `implementation` in the template. The upgrade rule (governing `:856–859`) adds a missing phase `model` as `inherit`, so existing projects keep today's behaviour until someone sets a tier. Brief §7 7/3 proposes `version: 2`. The current version is stated at governing `:691`, `:735` and README `:242` (S-1, S-6). Interview question 03/5. |
| **Decision** | "Bring the new keys to existing projects by raising the template to `version: 2`, missing keys added as `inherit`?" → "yes" — accepted by the Architect in interview question 03/5 |
