# ADR 2026-11-05 — B1 self-check: add an interview-structure check

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | B1 self-check: add an interview-structure check |
| **Status** | DECIDED |
| **Context** | B1 lists four self-check kinds: quotes, references, latest answer, index. In this bundle the Phase 01 verifier runs also failed on interview structure — a question asked while its prerequisite was "later" (frontier), and questions holding more than one decision (Phase 01 summary, runs 2 and 3; Phase 02 Performance Characteristics). Phase 02 O-8. Interview question 03/8. |
| **Decision** | "add a fifth B1 check: "every round holds only the frontier, and every question one decision"?" → "yes" — accepted by the Architect in interview question 03/8 |
