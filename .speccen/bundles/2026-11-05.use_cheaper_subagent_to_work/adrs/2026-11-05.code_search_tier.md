# ADR 2026-11-05 — Code-search tier: shared phase `model` key or a separate key

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | Code-search tier: shared phase `model` key or a separate key |
| **Status** | DECIDED |
| **Context** | Change A makes code search a subagent unit in Phases 02–05. Brief §7 7/1 proposes that it uses the phase's existing `phases.<phase>.model` tier, with no new key; "A separate key can be added later if a phase needs it, without breaking existing files." Phase 02: the Keys list (governing `:708–709`) and the fail-safe (`:940–941`) must change together for 04/05 (S-5). Interview question 03/4. |
| **Decision** | "Code searches share the phase's `model` tier, with no separate search key?" → "yes" — accepted by the Architect in interview question 03/4 |
