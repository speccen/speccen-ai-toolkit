# ADR 2026-11-05 — Code-search agent: `speccen-worker` or a host built-in search agent

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | Code-search agent: `speccen-worker` or a host built-in search agent |
| **Status** | DECIDED |
| **Context** | Brief A2 says "The worker returns findings only"; the evidence bundle ran Explore (a Claude Code built-in) on the session model (brief §1). Phase 02: `speccen-worker` has `model: inherit` and receives the resolved model at launch (governing `:1314–1315`); its "Never" list already forbids decisions and stray writes. The repository states nothing about how a host built-in agent takes a model; Host support (`:1347–1356`) warns hosts may not honour a requested model. Interview question 03/6. |
| **Decision** | "a code-search unit runs on `speccen-worker`, launched with the phase tier's model (not a host built-in agent)?" → "yes" — accepted by the Architect in interview question 03/6 |
