# ADR 2026-11-05 — The interview's bundle/store lookup and the code-search unit

<a id="decision"></a>

|     | Info |
| --- | --- |
| **Subject** | The interview's bundle/store lookup and the code-search unit |
| **Status** | DECIDED |
| **Context** | interview `:63–65` already allows "look it up — inline, or as a read-only `speccen-worker` unit" for bundle and store facts, but no Units row lists it; A1's new sentence ("a code search that is not launched as this unit runs inline") would leave it unlisted. Interview runs in Phases 01, 03, 04 (and stops/review). Phase 02 O-7. Interview question 03/7. |
| **Decision** | "widen the unit to "a search" (find and quote evidence for one question), in the code for Phases 02–05 and in the bundle and store for any phase that interviews, so the interview's lookup becomes a listed unit?" → "yes (option a)" — accepted by the Architect in interview question 03/7 |
