# Searches run on `speccen-worker`, not on a host's built-in search agent

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | "a code-search unit runs on `speccen-worker`, launched with the phase tier's model (not a host built-in agent)?" → "yes" (Architect, interview 03/6). |
| **Why** | The repository states nothing about how a host built-in agent takes a model, and Host support warns hosts may not honour a requested model. `speccen-worker` takes the resolved model at launch, and its Never list already forbids decisions and stray writes (ADR context, Phase 02). |
| **Alternatives** | A host's built-in search agent (the evidence bundle ran Explore on the session model) — not chosen (03/6). |
