# The fix budget defaults to 5 fix attempts; absence and the upgrade both mean 5

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | With no `fixes` set, an autonomous gate test makes up to 5 fix attempts. The template ships `fixes: 5` and the version-3 upgrade adds `fixes: 5`. An invalid value still counts as `1`. |
| **Why** | The Architect set the default to 5 (2026-11-12) with the ceiling of 10, so the delegate repairs routine gate-test faults without stopping; the progress and conclusions guards end a loop that does not converge. |
| **Alternatives** | Default `1`, keeping today's behaviour (brief §3, DD-17) — overridden; template `5` with absence `1` — not chosen; an invalid value counting as `5` — not chosen. |
