# Escape `|` in every table cell, also inside backticks

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | A bare bar character inside a code span still splits a GitHub table row. Inside a code span in a table cell, a backslash before the bar is consumed by the table, so the escape itself disappears there. In this feature, Phase 04 verifier runs 1 – 2 failed on split rows and on a requirement that lost its backslash. |
| **Why** | Escape the bar with a backslash in every table cell, inside backticks too; write a rule about the escape itself in words ("escaped with a backslash"). Count the cells of each row before the verifier runs. |
