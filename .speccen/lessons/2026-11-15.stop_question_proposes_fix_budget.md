# A gate stop question proposes the fix budget that follows the answer

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | After a gate stop, the Architect's answer sets which rows are re-checked and whether further fix attempts are allowed; without that, one verifier run follows and a failing row stops again. In this feature, the second Phase 03 stop came only from that default: the answer to the first stop said "apply", not how many attempts. |
| **Why** | In the stop round, put the fix budget to the Architect as its own question, with a proposal (for example "allow the phase's full fix budget again"), so a plain "yes" sets it. |
| **Alternatives** | n/a |
