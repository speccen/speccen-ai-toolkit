# Repair every case of a breach type, not only the cases the verifier names

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | A verifier names the cases it finds, not every case. In this feature's Phase 05, each repair of only the named checks was followed by a verifier run that found the next check with the same weakness (runs 3 – 7). |
| **Why** | After a failed row, search the whole artifact for the breach type and repair all cases before the next verifier run; one run then confirms the type instead of finding one case per run. |
