# A verifier that re-reads the whole phase finds new detail on every run

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | Under the rule "re-open the evidence of every row", the Phase 04 gate of this feature took 9 verifier runs and 4 stops. Runs 3 – 6 each found breaches the run before had not named, almost all in wording and records, none in a conclusion. Phase 05 took 4 runs with the same pattern. |
| **Why** | A verifier with the whole phase in scope always finds a next layer of detail, so the fix loop does not converge and its cost grows with each run. This is why the gate-check verifier settles only a capped list of code and repository claims and the self-check owns the bundle (version `26.1116.1`). Do not widen the verifier's scope again without a way to bound it. |
| **Alternatives** | Keep the full re-read and raise the fix budget — rejected: more attempts only pay for more layers. Drop the verifier — rejected: the code claims need an independent check. |
