# A text check reads only the place its plan row names — test it with a move test

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | Markdown skills have no test runner, so Phase 05 checks are string checks. A check that searches the whole file passes when the text moves out of its place; an "unchanged" check that only tests presence passes when the line is edited or moved. In this feature the Phase 05 accept needed eight verifier runs and three stop rounds, most of them for this cause. |
| **Why** | Scope each check to the row, bullet, section or block its Test Plan row names, and compare an "unchanged" part with the base commit in that place. Before the verifier runs, move each expected text out of its place in memory and confirm the check fails (the bundle's `files/phase-05-move-test.py`). |
