# Audit runs on the same day sort by id, so a run named before "baseline" is taken as the earlier run

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | `compare_scorecards.py` `load_all()` orders runs by `(date, id)`. A second run on the baseline's day named `2026-11-18.after` sorts before `2026-11-18.baseline`, so `compare` treats it as the first run and compares nothing — with no warning. |
| **Why** | A "no warning" check passed on an empty comparison until a mutation (a changed hash that must warn) exposed it. Give a later run an id that sorts after its baseline, and test every "no warning" check with a mutation that must warn. |
| **Alternatives** | n/a |
