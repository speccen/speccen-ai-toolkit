# A breach kept on purpose still counts as no progress — take it out of the round

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | The no-progress trigger looks only at whether a breach the run before named is still there. In this feature, a question replaced in Phase 03 was kept whole in its round "for traceability"; the next verifier run named it again and the run stopped. |
| **Why** | Move a replaced or superseded item out of the round into its own list (for example "Replaced questions") and link it from its record; never keep a named breach in place, whatever the reason. |
| **Alternatives** | n/a |
