# The audit scorer fails on Windows without UTF-8 mode, and a fix changes the rubric hash

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | `build_scorecard.py` writes `scorecard.md` with `write_text()` and no `encoding` (line 391). On Windows Python then writes cp1252 and stops with `UnicodeEncodeError` on `★`. Running Python in UTF-8 mode (`-X utf8`) avoids it. |
| **Why** | The rubric hash covers the scorer's bytes (`compare_scorecards.py` `rubric_hash()`), so any fix to the scorer changes the hash, and every later run reads "not like-for-like" against earlier runs. A fix needs its own decision on that break; until then, run the scripts in UTF-8 mode on Windows. |
| **Alternatives** | n/a |
