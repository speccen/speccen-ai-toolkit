# Fix the term list before writing STE seeds

[Index](../index.md)

---

|     | Info |
| --- | --- |
| **What** | The gate verifier found new STE defects on each re-check of the Phase 04 audience seeds: one row needed six verifier runs and four stop rounds (04/4 – 04/7). Each pass fixed only the named phrases, and the next pass found another name for the same actor or thing. |
| **Why** | A full rewrite with one fixed term per actor and per thing (main session, worker, verifier, model tier, search question, evidence) passed after one more cycle. Setting that list before writing avoids the loop. |
